# Дифференциальная проводимость, L/xi_Delta = 1

В существующем проекте Keldysh настройки находятся в Keldysh/main.cpp, в функции main.
Режим settings.mode = "conductance" запускается без аргументов (Ctrl+F5, Release x64).
Если в свойствах отладки Visual Studio остались аргументы, удалите их: они переопределяют режим.

Настройки:
    settings.physical.L_N = 1.0 * std::sqrt(settings.physical.diffusion() / settings.physical.Delta);
    settings.sweep_start = 3.0;
    settings.sweep_end = 0.5;
    settings.sweep_step = 0.1;

Множитель 1.0 задаёт L/xi_Delta, где xi_Delta=sqrt(hbar D_N/Delta).
В исходной программе длина измеряется в xi_S, поэтому при Ksi_N=1 и Delta=1.76
получается L_N=1.889442153601582. Физическая нормировка решателя не изменена.

Результат: C:/Users/user/source/repos/aleksneilo/keldysh/Ricatti/conductance_L1.txt
Настройка имени: settings.conductance_path.
Каждый новый запуск перезаписывает этот файл.
Строки # — комментарии; затем четыре столбца, разделённые табуляцией:

V    L_N    I    dI/dV

V = e V_phys / Delta_phys (ось напряжения рисунка).
L_N = L / xi_S (длина в единицах исходной программы).
I = e I_phys / (G_N Delta_phys).
dI/dV = (dI_phys/dV_phys) / G_N.
Здесь G_N — нормальная проводимость данного образца.
Для графика используйте столбцы 1 и 4. В нормальном состоянии ожидается dI/dV=1.

Внутри решателя напряжение по-прежнему eV/(k_B Tc): программа умножает V из сетки на Delta.
Ток решателя I_star пересчитывается как I=I_star/(physical.conductance()*Delta).

Расчёт идёт от 3 до 0.5 включительно: 26 точек.
Начальное приближение переносится с предыдущего напряжения.
Производная во внутренних точках:
    dI/dV[i] = (I[i+1]-I[i-1])/(V[i+1]-V[i-1]).
На концах применяются односторонние формулы второго порядка.
Строки сохраняются, когда рассчитаны необходимые соседи.
Успешное завершение отмечается строкой # COMPLETE points=26.
Без неё файл может содержать только часть расчёта.
Ошибка сохранения тока показывается в консоли; current_conservation_passed=1
означает только выполнение этого критерия, а не сходимость по всем сеткам.

Код обхода сетки, нормировки и записи: Keldysh/sns/runner.cpp, ветка conductance.
Код сетки и разностной производной: Keldysh/sns/current.cpp,
функции voltage_grid и differentiate_current.

Первый запуск использует NF=2, Nx=25, Neps=16, eta/Delta=0.001, T=0.
Это предварительный тест. Для сравнения со статьёй необходимо отдельно увеличивать
NF, Nx, Neps и проверять устойчивость именно dI/dV. Ошибка интеграла тока
усиливается при дифференцировании. Шаг 0.1 не разрешает узкие пики:
после сходимости тока уменьшите шаг около интересующих особенностей.
Сохраните исходный результат под другим именем перед повторным расчётом.

Командная строка готовой общей программы:
    Keldysh.exe conductance 3 0.5 0.1 2 25 16 result.txt
Аргументы: начало, конец, положительный шаг (в eV/Delta), NF, Nx, Neps, файл.
